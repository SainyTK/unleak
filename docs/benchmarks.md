# Benchmarks

Benchmarks are supporting proof, not the primary onboarding path.

## Run the harness

```bash
python3 benchmarks/run_benchmarks.py
```

## Included scenarios

The current committed scenarios cover:

- retail branch performance
- support ticket trends with raw free text present
