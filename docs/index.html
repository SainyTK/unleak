unleak

Let agents analyze data without leaking the raw rows.

unleak keeps sensitive CSV, SQLite, and project data local. It asks the agent to discover metadata first, generate deterministic safe artifacts on the operator machine, and validate release before the model sees anything.

Start with the README, then run python3 evals/llm_run.py --agent claude --agent codex to exercise the current live-agent smoke path when those CLIs are installed.
